# پورتال نرم‌افزارهای مهندسی

سایت ایستا (بدون سرور) برای GitHub Pages.

## ساختار
- `index.html`: صفحه‌ی پورتال (دست نزنید)
- `config.js`: مشخصات شما و فهرست برنامه‌ها (**فقط این فایل را ویرایش کنید**)
- `beam/ framelab/ static/ dynamics/ buckling/ beton/ moqta/ calc/`: هر برنامه در یک پوشه، با فایلی به نام `index.html`
- `sw.js`, `manifest.webmanifest`, آیکون‌ها: نصب روی دستگاه و کار آفلاین

## به‌روزرسانی یک برنامه
در GitHub وارد پوشه‌ی برنامه شوید ← `index.html` ← مداد ← محتوا را پاک و کد جدید را بچسبانید ← **Commit changes**. لینک همان می‌ماند و بعد از حدود یک دقیقه فعال می‌شود.

## افزودن برنامه‌ی جدید
۱. پوشه‌ی جدید بسازید (مثلاً `truss`) و فایل برنامه را با نام `index.html` در آن بگذارید.
۲. در `config.js` یک بلوک به `APPS` اضافه کنید که `id: 'truss'` داشته باشد.

## یک‌بار تنظیم
در `index.html` عبارت `USERNAME.github.io/REPO` را با آدرس واقعی سایت عوض کنید (برای پیش‌نمایش زیبا هنگام ارسال لینک در تلگرام).
